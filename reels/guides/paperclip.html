1. What is Paperclip?

Paperclip is a free, open-source (MIT licence), self-hosted app (a Node.js server with a React dashboard) that organises a team of AI agents like a company. No Paperclip account is required.

  • Org chart for agents: roles, job titles, reporting lines and permissions (for example a CEO agent, a developer agent, a marketing agent).
  • Goals → tasks: define a goal; work is split into tasks assigned to agents.
  • Budgets and cost control: company, agent and project budgets, threshold alerts, and automatic pauses at limits you set.
  • Governance: review and approval stages, and the ability to pause, resume or stop agents.
  • Bring your own agents: works with tools such as Claude Code, Codex and other CLI or HTTP agents.

The README describes the flow in three steps: Define the goal → Hire the team → Approve and run.

Read this first.
  • Paperclip organises agents. The thinking is done by an AI model you connect (for example Anthropic, OpenAI or OpenRouter), and those usually cost money per use. Set a budget before you start.
  • AI agents are not real employees. They make mistakes. Review their work before you use or publish it.
  • Never share API keys with anyone or paste them into chats.

3. Install (the guided quickstart)

  1. Install Node.js 24.11+ and confirm it in a terminal: 
    node -v
  2. Run the official guided setup: 
    npx paperclipai@latest onboard --yes
    It sets Paperclip up on your own computer. Your configuration and data are kept locally, and a database is created for you automatically.
  3. Open the dashboard in your browser. The README gives the local address as http://localhost:3100.
  4. Follow the onboarding screens to connect your AI provider and create your company.
Just want to try it first? The README has a test-drive mode that starts a temporary instance with a CEO agent already set up, for example: 
ANTHROPIC_API_KEY=your_key npx paperclipai test-drive
For OpenAI: OPENAI_API_KEY=your_key npx paperclipai test-drive --harness codex
Error "E404 for paperclipai"? If your computer uses a private npm registry, force the public one: 
npx --registry https://registry.npmjs.org paperclipai@latest onboard --yes
To change settings later: npx paperclipai configure

4. Your first company: just 2 agents

Don't start with ten agents. Start with two and one small, clear goal.

StepWhat to do
1. Define the goalMake it specific, e.g. "Write one helpful blog post about [your topic] this week."
2. Hire 2 agents🔎 Researcher: finds facts, sources and examples.
✍️ Writer: turns the research notes into a clear draft.
3. Set a small budgetUse the budget settings so work pauses at your limit.
4. Approve and runStart the work and watch progress on the dashboard.
5. ReviewCheck the research and the draft yourself. Fix anything wrong before publishing.

When that works well, add a third agent (for example an editor or a social-media agent).

5. Tips to avoid surprises

  • Small, specific goals waste fewer tokens than vague ones.
  • Check the costs view regularly; budgets help stop runaway spending, but reported usage can lag a little.
  • Keep humans in the loop: use review/approval stages for anything that matters.
  • Stay local first. The quickstart runs in a local mode. For access from other devices, the README describes private-network options (e.g. --bind lan or --bind tailnet) and Docker deployment; read those docs before exposing it.
  • Commands change between releases: always check the README on GitHub.

6. Your setup checklist

  • Node.js 24.11+ installed (node -v)
  • API key from one AI provider ready (kept private)
  • Ran npx paperclipai@latest onboard --yes
