Immich: Your Own Google Photos
Full Setup Guide

1. What is Immich?

Immich is a free, open-source (AGPL-3.0) photo and video library that you run on your own computer or home server. Its phone apps back up your photos to your machine instead of a cloud company's servers.

  • AI search: type a description like "beach with red umbrella" and it finds matching photos.
  • Face recognition: groups photos by the people in them.
  • Phone backup: iOS and Android apps upload new photos automatically.
  • Timeline, albums and sharing, much like Google Photos.
Try it before installing: open demo.immich.app and click "Login as demo user". Try the search with a description of a photo.

2. Is it right for you?

Good fit if…Think twice if…
You want your photos on your own hardware
You have a computer that can stay switched on
You're comfortable following terminal steps		You want zero maintenance
You don't have space for a second backup
You never want to deal with updates
The honest catch: you run it yourself. Storage, updates and backups are your job. Immich is not a backup on its own: keep a second copy of your photos somewhere else.

4. Step-by-step install (Docker Compose)

These are the main steps from the official quick start. Commands and file names can change between releases, so keep docs.immich.app open while you install and follow it if anything differs.

  1. Install Docker and the Docker Compose plugin (docs.docker.com). Check it works: 
    docker compose version
  2. Make a folder for Immich and go into it: 
    mkdir ./immich-app
cd ./immich-app
  3. Download the two official files (docker-compose.yml and example.env) from the latest Immich release, using the links in the official quick start. Rename example.env to .env.
  4. Edit .env:
    • UPLOAD_LOCATION: the folder (on a disk with plenty of space) where your photos will live.
    • DB_PASSWORD: change it to your own value (the docs suggest letters and numbers only).
    • Optionally set your time zone, as described in the file.
  5. Start Immich: 
    docker compose up -d
  6. Open the web app in your browser at http://<your-computer's-IP>:2283 (or http://localhost:2283 on the same computer). The first account you create becomes the admin.

5. Connect your phone

  1. Install the Immich app from the App Store or Google Play.
  2. Enter your server address (the same http://…:2283 address) and log in.
  3. Open backup settings, choose the albums to back up and turn backup on. The first upload can take a long time.
Away from home? By default the server is only reachable on your home network. For outside access, use a private network tool (for example a VPN) as described in the docs. Don't expose it to the internet without understanding the security steps.

6. Use the AI search

  • Wait until the initial processing finishes (the admin page shows the job queues). AI search and face groups appear as photos are processed.
  • In the search bar, describe the photo: "dog on a sofa", "sunset at the beach", "birthday cake".
  • Name people in the People section to search by person.

7. Backups (don't skip this)

  • Follow the 3-2-1 idea: 3 copies, on 2 different devices, with 1 copy somewhere else.
  • Back up your photo folder (UPLOAD_LOCATION) and the database. The official docs have a "Backup and Restore" page.
  • Test a restore once, so you know your backup actually works.

8. Updates

  • Read the release notes on GitHub before updating; some releases need extra steps.
  • Then, in your Immich folder: 
    docker compose pull
docker compose up -d

9. Your setup checklist

  • Tried the demo at demo.immich.app
  • Computer with at least 6 GB RAM / 2 cores (8 GB / 4 cores better) that stays on
  • Enough storage + a separate backup location
  • Docker + Docker Compose plugin installed
  • docker-compose.yml and .env downloaded; UPLOAD_LOCATION and DB_PASSWORD set
  • docker compose up -d running; admin account created at port 2283
  • Phone app connected and backup turned on
  • Backup of photos and database scheduled, restore tested
